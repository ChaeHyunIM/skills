# 이미지와 설명을 한 카드로 묶기

이미지와 그 설명을 함께 읽어야 할 때 한 카드에 넣는다. 이미지 바로 옆이나 아래에 해석이나 근거를 붙여야 하는 경우에 쓴다. 모든 이미지를 카드로 감쌀 필요는 없다. 사용자가 배치를 따로 지정하면 그에 따른다.

이 방식은 2026-09-10 Chaewun 제안서 작업에서 사용자가 선택했다.

## 이미지를 옆에 둘지 위에 둘지 정하기

가로세로 비율과 함께, 실제 화면에서 이미지 속 글자나 제품이 잘 보이는지 확인한다. 설명을 붙였을 때 한쪽에 빈 공간이 너무 많이 남는지도 본다.

| 이미지와 설명 | 먼저 시도할 배치 | 배치를 바꿔야 할 때 |
|---|---|---|
| 줄여도 잘 보이는 가로 이미지와 짧은 설명 | 이미지는 왼쪽, 설명은 오른쪽에 둔다. 이미지 너비는 카드의 60~70%부터 시도한다. | 이미지 속 글자가 너무 작거나 위아래에 빈 공간이 많이 남으면 이미지를 위로 옮긴다. |
| 글자가 많은 배너·차트·스크린샷, 아주 넓고 낮은 이미지 | 이미지를 위에 두고 카드의 전체 너비를 쓰게 한다. 설명은 아래에 둔다. | 설명이 길면 주제별로 정리하고, 뒤에서 설명해도 되는 내용은 카드 밖으로 옮긴다. |
| 정사각형이나 세로로 긴 제품 사진과 짧거나 중간 길이의 설명 | 이미지와 설명을 나란히 둔다. 이미지 너비는 카드의 40~50%부터 시도한다. | 작은 화면에서 설명을 읽기 어려워지면 이미지를 위로 옮긴다. |
| 통째로 줄이면 읽기 어려운 긴 포스터나 인포그래픽 | 이미지를 위에 넓게 보여주고 원본 보기 링크를 둔다. | 카드 높이를 줄이려고 중요한 내용을 자르거나 이미지를 찌그러뜨리지 않는다. |

위 비율은 화면을 보며 조절한다. 앞뒤 내용을 읽는 순서나 사용자 요청에 따라 설명을 왼쪽에 둘 수도 있다. 변화를 주기 위해 이미지와 설명의 좌우를 번갈아 바꾸지는 않는다.

## 테두리와 여백 넣기

- 이미지와 설명을 카드 하나에 넣는다. 테두리는 1px로 얇게 두고 바깥 모서리를 둥글게 한다. 내용이 모서리 밖으로 나오지 않게 `overflow: hidden`을 쓴다. 기본적으로 그림자는 넣지 않는다.
- 카드와 이미지를 감싼 요소에는 안쪽 여백(`padding`)을 주지 않는다. 이미지가 카드 가장자리에 닿게 한다. 이미지 자체에 둥근 모서리나 안쪽 액자를 추가하지 않는다.
- 안쪽 여백은 설명에만 준다. 기본은 `space-6`, 좁은 화면에서는 `space-4`~`space-5`를 쓴다. 앞의 소개 문장과 카드 사이는 `space-3`부터 시도한다. 바깥 요소의 `gap`과 문단의 `margin`까지 합쳐 화면에서 실제로 얼마나 떨어지는지 확인한다.
- 배경, 테두리, 글자 색은 [정해진 CSS 변수](vbg-api.md)를 쓴다. 사진의 배경색을 추측해 빈 곳에 덧칠하지 않는다. 다크 모드에서도 원본 이미지의 색을 바꾸지 않는다.

## 이미지 내용 보존하기

- **이미지에 글자, 로고, 차트나 제품 포장 정보가 있으면 잘라내지 않고 전체를 보여준다.** 기본은 `width: 100%; height: auto`로 둔다. 나란히 놓았을 때 잘 읽히지 않으면 이미지를 위로 옮긴다. 꽉 채우기 위해 `object-fit: cover`로 내용을 자르거나 `fill`로 왜곡하지 않는다.
- 여백을 잘라도 되는 사진만 `height: 100%; object-fit: cover`를 쓸 수 있다. 중요한 피사체가 잘리지 않도록 `object-position`을 조절한다. 이미지 파일에 원래 들어 있던 여백과 CSS로 넣은 여백을 구분한다.

## 설명 쓰기와 작은 화면에 맞추기

- `figure` 안에 이미지와 설명(`figcaption`)을 둔다. 이미지의 대체 텍스트에는 이미지가 전달하는 가장 중요한 내용을 적는다.
- 이미지에 이미 있는 제목을 설명에 반복하지 않는다. 설명에는 이미지를 어떻게 읽어야 하는지, 판단의 근거가 무엇인지, 어떤 조건에서 성립하는지 적는다. 일본어 인용에는 `lang="ja"`를 단다.
- 설명이 짧으면 한 문단으로 쓴다. 서로 다른 근거가 둘일 때만 두 묶음으로 나눈다. 안에 카드를 더 넣거나 설명을 둥근 배지로 꾸미지 않는다.
- 본문이 길다고 폰트를 줄여 맞추지 않는다. 이미지를 위로 옮기거나 설명 일부를 카드 다음 문단으로 옮긴다. 필요한 내용은 남긴다.
- 나란히 놓았을 때 읽기 어려워지는 너비에서는 이미지를 위에, 설명을 아래에 둔다. 우선 800px을 기준으로 시도하되, 실제 카드 너비와 설명에 쓰인 언어를 보고 조절한다. 모바일에서도 이미지는 전체 너비를 쓰고 원래 가로세로 비율을 유지한다.

## 페이지 안에서 쓰는 예시

아래 `vbg-custom-*` 클래스는 이 페이지의 본문 안에 정의한다. 공통 CSS 파일에 추가하지 않는다. 기본 배치는 이미지 위, 설명 아래다. 나란히 놓아도 이미지와 설명이 잘 읽힐 때만 `data-layout="side"`를 쓴다.

```html
<style>
.vbg-custom-media-card {
  display: grid;
  margin: var(--vbg-space-3) 0 0;
  padding: 0;
  overflow: hidden;
  border: 1px solid var(--vbg-border-default);
  border-radius: var(--vbg-space-4);
  background: var(--vbg-surface-primary);
}
.vbg-custom-media-card > img {
  display: block;
  width: 100%;
  height: auto;
  min-width: 0;
}
.vbg-custom-media-copy {
  min-width: 0;
  padding: var(--vbg-space-6);
  align-self: center;
}
.vbg-custom-media-copy > :first-child { margin-top: 0; }
.vbg-custom-media-copy > :last-child { margin-bottom: 0; }
@media (min-width: 801px) {
  .vbg-custom-media-card[data-layout="side"] {
    grid-template-columns: minmax(0, 2fr) minmax(0, 1fr);
    align-items: start;
  }
}
@media (max-width: 800px) {
  .vbg-custom-media-copy { padding: var(--vbg-space-5); }
}
</style>
<figure class="vbg-custom-media-card" data-layout="stack">
  <img src="IMAGE_DATA_URI" alt="이미지가 전달하는 가장 중요한 내용">
  <figcaption class="vbg-custom-media-copy">
    <p>이미지를 어떻게 읽어야 하는지 설명한다.</p>
  </figcaption>
</figure>
```

예시의 이미지, 대체 텍스트, 문단은 실제 자료로 바꾼다. 나란히 놓은 이미지와 설명의 높이가 너무 다르면 위아래로 배치해 본다.

## 화면에서 확인하기

페이지를 미리 볼 때 다음을 함께 확인한다.

- 이미지가 잘리지 않고, 이미지 속 글자를 읽을 수 있는가.
- 카드 안에 이유 없이 빈 공간이 많이 남거나 이미지 가장자리에 불필요한 여백이 생기지 않았는가.
- 앞의 안내 문장과 카드 사이가 너무 멀거나 붙어 있지 않은가.
- 모바일과 다크 모드에서도 이미지와 설명이 잘 보이는가.

화면을 직접 볼 수 없었다면 확인했다고 말하지 않는다.
