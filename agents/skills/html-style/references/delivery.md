# HTML 파일 만들기와 게시하기

HTML 파일을 만들거나 게시할 때 읽는다. 사용자가 게시까지 요청했는지는 앞선 대화에서 확인한다. 게시 요청이 있으면 지정된 도구로 올리고, 파일만 요청했다면 완성된 파일을 전달한다. 이미 받은 승인을 다시 묻지 않는다.

## 본문과 스타일을 한 파일로 합치기

본문 파일은 `.vbg-report`로 감싼 내용과 이 페이지에만 필요한 `<style>`로 만든다. `scripts/build.sh`는 제목, `assets/font.css`·`brand.css`·`page.css`, 본문을 차례로 이어 붙인다. 결과에는 `<title>`, `<style>`, 본문이 들어 있고, `<html>`, `<head>`, `<body>`는 들어 있지 않다.

아래 `${CLAUDE_SKILL_DIR}`는 Claude Code가 제공하는 경로다. Codex 등에서는 이번에 읽은 `SKILL.md`가 있는 폴더의 실제 경로로 바꿔 쓴다. 스킬이 특정 홈 폴더에 설치돼 있다고 가정하지 않는다.

```bash
${CLAUDE_SKILL_DIR}/scripts/build.sh "<페이지 제목>" body.html out.html
${CLAUDE_SKILL_DIR}/scripts/preview.sh out.html
```

파일을 어디서 열거나 게시할지에 따라 나머지 태그를 붙인다.

| 파일을 사용할 곳 | 태그를 붙이는 방법 |
|---|---|
| `<html>`, `<head>`, `<body>`를 자동으로 붙이는 게시 도구 | 도구가 받는 형식에 맞춰 본문과 스타일을 전달한다. 자동으로 붙는 태그를 중복해서 넣지 않는다. |
| 브라우저에서 직접 열 파일이나 완전한 HTML 문서를 요구하는 호스팅 | `<!doctype html>`, `<html lang="ko">`, `<head>`, `<body>`를 붙인다. 제목과 공통 스타일은 `<head>`에, 내용은 `<body>`에 넣는다. 문자 인코딩과 화면 너비를 설정하는 `charset`, `viewport` 메타 태그도 넣는다. |
| 기존 사이트 프로젝트 | 그 프로젝트에서 쓰는 문서 구조와 배포 방법을 따른다. 요청 없이 새 게시 환경을 만들지 않는다. |

CSS는 `<style>`에 넣는다. 폰트와 이미지는 파일 내용을 문자열로 바꾼 data URI로 넣어 HTML 파일 하나만으로 열 수 있게 한다. 폰트가 들어 있어 기본 파일 크기는 약 2.8MB다. `build.sh`가 알려주는 실제 크기가 게시 도구의 한도를 넘지 않는지 확인한다.

## 아이콘 가져오기

아이콘이 필요하면 Phosphor SVG를 가져와 HTML 안에 넣는다. `<name>`은 필요한 아이콘 이름으로 바꾼다.

```bash
curl -s https://unpkg.com/@phosphor-icons/core/assets/regular/<name>.svg
```

가져온 SVG에서 `width`와 `height`를 지우고 `viewBox`는 남긴다. 색은 `fill="currentColor"`로 설정한다.

## 화면 확인하기

`preview.sh`는 `build.sh`의 결과에 필요한 태그를 붙여 임시 파일 `.preview.html`을 만든다. 다음 세 화면에서 페이지 맨 아래까지 캡처한다.

| 화면 | 브라우저 창 크기 |
|---|---|
| 데스크톱, 라이트 모드 | 1280×800 |
| 데스크톱, 다크 모드 | 1280×800 |
| 모바일, 라이트 모드 | 390×844 |

이미 `<html>`, `<head>`, `<body>`를 갖춘 문서는 이 스크립트에 다시 넣지 않고 브라우저에서 직접 연다.

캡처로는 내 컴퓨터에서 화면이 어떻게 보이는지 확인할 수 있다. 게시 도구가 HTML을 바꾸거나 외부 파일을 차단하는 동작, 사용자가 테마를 고르는 동작까지 확인한 것은 아니다. 수정한 내용이 이런 동작과 관련되면 실제 게시 화면에서도 확인한다. 계산기, 필터, 펼치기 버튼은 직접 조작해 본다.

## 게시 도구에서 확인할 사항

`assets/page.css`는 문서의 최상위 요소에 `data-theme="dark|light"`가 있으면 그 설정에 맞춰 페이지 색을 바꾼다. 이 속성이 없으면 시스템 테마를 따른다. 페이지 안에 테마를 바꾸는 버튼을 따로 만들지 않는다.

아래 제한은 이전 스킬에 남아 있던 기록이다. 어떤 게시 도구의 제한인지 적혀 있지 않으므로, 지금 사용하는 도구에도 해당하는지 확인한 뒤 적용한다.

- **외부 파일:** 외부 스타일시트는 Google Fonts만, 스크립트는 일부 CDN만 허용한다는 기록이 있다. 외부 스크립트가 필요하면 현재 도구에서 허용하는 주소를 확인한다.
- **파일 크기:** 페이지당 16MB라는 기록이 있다. 다른 도구에도 같은 한도가 있다고 가정하지 않는다.
- **공유 버전:** 공유한 버전이 핀으로 고정되는 도구에서는 파일을 고쳐도 외부에 이전 버전이 보일 수 있다. 그런 경우 새 버전을 공유하려면 핀도 옮겨야 한다고 사용자에게 알린다.

## 기존 페이지 수정하기

기존 페이지를 고쳐 게시할 때는 같은 URL을 유지한다. 버전 기능이 있는 도구에서는 새 버전으로 저장하고 버전을 구분할 이름을 붙인다. 도구가 같은 URL의 내용을 바꾸는 기능을 지원하지 않으면 완성된 파일을 보관하고 사용자에게 알린다. 임의로 다른 URL에 올리지 않는다.
