# 구현할 티켓 고르기

티켓 번호 없이 `implement`를 호출했을 때 사용한다.

- 트래커에서 `ready` 티켓을 모은다. 다시 작업할 `blocked` 티켓과 진행 중인 `in-progress`·`awaiting-review` 티켓도 함께 보여 준다.
- 트래커의 선행 작업 관계와 연결 PR의 머지 여부를 확인한다. 후보마다 번호와 제목, 목표, 관련 앱, 선행 작업 상태, 구현 계획 한 줄을 보여 준다.
- 선행 작업이 아직 열려 있으면 “아직 시작할 수 없음”으로 표시하고 추천에서는 뺀다. 목록에서 지우지는 않는다. 선행 PR이 머지되면 시작할 수 있다.
- 의존 관계나 우선순위를 보고 추천할 티켓이 있으면 하나를 표시한다.
- 후보가 없으면 없다고 보고하고 멈춘다.
- 어느 티켓을 어떤 방향으로 구현할지 선택받은 뒤 진행한다.
