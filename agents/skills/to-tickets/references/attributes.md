# 티켓 속성 정하기

트래커가 제공하는 크기(estimate), 주기(cycle), 우선순위(priority), 마감일(due date)만 제안한다. 없는 속성을 만들거나 속성 값을 본문에 중복해서 적지 않는다.

- **크기**는 다른 티켓과 비교한 불확실성, 복잡도, 작업 범위다. 소요 시간이 아니므로 날짜로 바꾸지 않는다. 팀이 사용하는 척도에서 값을 고른다. 티켓 하나가 유독 크면 최대값을 붙이기보다 나눌 수 있는지 살핀다.
- **작업 주기**는 선행 작업이 끝나는 순서에 맞춰 배치한다. 해당 주기에 이미 잡힌 일과 이번 작업을 합쳐 모두 진행할 수 있을 때만 넣는다. 선행 작업이 그 주기 안에 끝나지 못하면 다음 주기나 `unset`으로 둔다. 팀이 처리할 수 있는 양을 지어내지 않는다.
- **우선순위**는 근거에 긴급하다는 내용이 없으면 기본값을 둔다. `Urgent`는 알림이나 운영 대응을 일으킬 수 있으므로 사용자나 출처가 명시한 경우에만 쓴다.
- **마감일**은 사용자나 출처가 정한 실제 날짜 제약이 있을 때만 넣는다. 크기, 처리량, 작업 주기에서 계산하지 않는다. 예상 완료일을 마감일로 만들지 않는다.
- 사용자가 이미 지정한 값은 보존한다. 근거가 없는 값은 제안할 때 `unset`으로 표시하고, 티켓을 만들거나 고칠 때 해당 속성은 건드리지 않는다.
