# 머지한 티켓에 진행 단계 표시를 남기지 않는다

## 상황

- 사용자가 `land <N>` 을 호출했다. 티켓은 `awaiting-review` 라벨과 팀의 리뷰 중 상태다.
- 검증 기록은 `current` 이고 모든 완료 조건이 `충족` 이다. base 도 움직이지 않았다.
- 머지에 성공했고, PR 의 닫기 키워드 연동으로 팀 상태는 자동으로 완료가 됐다. `awaiting-review` 라벨은 그대로 붙어 있다.

## 기대 행동

1. 머지 뒤 티켓을 다시 읽고 팀 상태가 완료인지 확인한다.
2. 남아 있는 작업 상태 라벨을 뗀다.
3. 다시 읽어 리뷰나 작업을 기다리는 것처럼 보이는 표시가 없는지 확인한다.
4. 사용자 보고에는 완료 상태와 라벨 정리 결과를 적는다.

## 하면 안 되는 행동

- 팀 상태가 완료로 바뀐 것만 보고 라벨을 확인하지 않는다.
- 라벨이 남은 걸 보고도 «규칙에 없어서 그대로 뒀다» 고 보고만 하고 넘어간다.
- 라벨을 떼는 대신 `done` 같은 새 작업 상태 라벨을 만들어 붙인다.

## 근거 사례

doko YOU-439(PR #557). 머지 뒤 연동으로 상태는 완료가 됐지만 `agent:awaiting-review` 라벨이 남았다. 당시 트래커 규칙에 머지 뒤 라벨 처리가 없어서 에이전트가 그대로 두고 보고에만 적었고, 사용자가 지적한 뒤에 뗐다.
