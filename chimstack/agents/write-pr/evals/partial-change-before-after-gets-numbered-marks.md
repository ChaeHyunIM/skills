# 화면 일부만 바뀐 Before·After에는 같은 번호를 붙이고 번호 순서로 설명한다

## 상황

- 기존 화면에서 카드 안의 줄 하나를 빼고, 일부 행을 숨기고, 안내 문구 한 단어를 지운 PR의 본문을 쓴다.
- Before·After는 둘 다 화면 전체 캡처다. 바뀐 곳은 화면의 일부이고, 나머지는 두 장이 같다.
- 리뷰어가 지적한 다른 기록물 문제(예: Before 누락)를 고치고 있는 중이다.

## 기대 행동

1. 붙이기 전에 이미지마다 «봐야 할 곳이 바로 보이는가»를 판단한다. 화면 전체 중 일부만 바뀌었으면 표시 대상이다.
2. 바뀐 곳마다 번호를 정한다. Before와 After에서 같은 자리에 같은 번호를 쓴다. 사라진 요소는 Before에서는 그 요소를, After에서는 그것이 있던 자리를 가리킨다.
3. 표시가 읽힐 해상도로 준비한다. 너무 작게 줄인 캡처에는 번호가 보이지 않고, 원본이 너무 크면 번호가 상대적으로 작아진다. 필요하면 다시 찍거나 크기를 맞춘다.
4. 그린 이미지를 직접 열어 화살촉이 의도한 글자나 줄에 닿는지, 번호가 다른 글자를 덮지 않는지 확인한다.
5. 표 바로 아래에 번호 순서로 «무엇이 어떻게 달라졌는지»를 한 줄씩 쓴다.
6. 지적받은 문제 하나를 고칠 때도 기록물 첨부 규칙(Before·After, 표시, 설명, 첨부 방식)을 처음부터 다시 훑고 함께 고친다.

## 하면 안 되는 행동

- Before·After 표만 붙이고 무엇이 달라졌는지는 리뷰어가 두 장을 번갈아 보며 찾게 둔다.
- 번호만 그리고 이미지 아래 설명을 빼먹거나, Before와 After에서 번호를 다른 자리에 쓴다.
- 좌표를 어림해서 그린 뒤 열어 보지 않아, 화살표가 옆 단어를 가리킨 채로 올린다.
- 지적받은 항목만 고치고, 같은 첨부 규칙의 다른 항목은 다시 확인하지 않는다.

## 근거 사례

doko PR #582. 처음에는 After 캡처만 올렸다. Before를 추가하라는 지적을 받고 Before·After 표로 고쳤지만, 번호·화살표와 번호별 설명은 여전히 없었다. 사용자가 «뭐가 달라졌고 그걸 넘버링해서 설명을 붙여 주는 플로우를 스킬에 명시했던 것 같다»고 다시 지적했다. 원인은 셋이었다.
- 표시 규칙은 «봐야 할 곳이 바로 보이지 않으면»이라는 조건문이다. 이미지마다 이 판단을 하지 않고 넘어갔다.
- 첫 지적(Before 누락)만 고치고 첨부 규칙 전체를 다시 보지 않았다.
- 기본 축소 배율(0.25)로 찍어 둔 캡처라 표시를 그릴 생각을 하지 않았다.

다시 찍을 때 원본 해상도에서는 번호가 너무 작았다. 절반으로 줄여 그렸다. 첫 시도에서 문구 쪽 화살표가 「定員」 대신 옆 단어를 가리켜, 열어 보고 좌표를 고쳤다.
