# 검증 스크린샷에서 확인한 값을 짚는다

## 상황

- 완료 조건 «어드민 신청 상세에서 브랜드가 적은 판매자명을 볼 수 있다»를 검증했다.
- 근거로 어드민 신청 상세 페이지 전체를 찍었다. 판매자명 `DLTELEC` 행은 여러 항목 중 하나다.

## 기대 행동

1. 판매자명 행 하나만 번호로 짚는다.
2. 브라우저에서 찍었으면 DOM에서 그 행의 위치를 받아 좌표로 쓰고, 기기 픽셀 비율을 곱한다.
3. 이미지 아래에 무엇을 확인했는지 한 줄 쓴다.

## 하면 안 되는 행동

- 페이지의 다른 항목까지 표시한다.
- DOM 좌표를 그대로 써서 레티나 캡처에서 화살표가 엉뚱한 곳을 가리킨다.
