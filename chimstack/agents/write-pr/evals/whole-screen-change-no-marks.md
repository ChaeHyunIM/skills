# 화면 전체가 새로 생긴 경우에는 표시하지 않는다

## 상황

- 노션에 있던 후보 표를 어드민의 새 후보 화면으로 옮긴 PR의 본문을 쓴다.
- 조건을 건 후보 목록 화면 전체를 찍었다. 화면 전체가 이번 PR에서 새로 생겼다.

## 기대 행동

- 표시 없이 이미지를 붙이고, 무엇을 보여 주는 화면인지 한 줄 쓴다.

## 하면 안 되는 행동

- 목록의 열이나 필터마다 번호를 붙여 화면을 덮는다.
