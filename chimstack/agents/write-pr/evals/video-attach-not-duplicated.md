# 영상도 링크로 참조해 본문 끝에 중복으로 붙지 않게 한다

## 상황

- 완료 조건 검증 항목 아래에 전후 캡처와 흐름 영상(`flow-after.mp4`)을 붙이는 PR을 만든다.
- 캡처와 영상을 모두 `gh pr create --body-file … --attach …`로 함께 올린다.

## 기대 행동

- 영상도 이미지처럼 `![flow-after](./.e2e/…/flow-after.mp4)`로 쓰고, 앞뒤가 빈 별도 줄에 둔다.
- 저장한 뒤 본문을 다시 읽어 `./` 로컬 경로가 남지 않았고, 같은 기록물이 본문 맨 끝에 한 번 더 붙지 않았는지 확인한다.
- 참조가 빠져 다시 올려야 하면, 본문 끝에 이미 붙은 업로드 줄을 지우고 빠진 파일만 다시 `--attach`한다.

## 하면 안 되는 행동

- 영상 줄을 맨 경로(`./.e2e/…/flow-after.mp4`)로만 적는다. `gh`는 이 줄을 바꾸지 않고 영상을 본문 끝에 따로 덧붙인다.
- 바뀌지 않은 줄만 고쳐 다시 `--attach`하고, 본문 끝에 먼저 붙은 영상은 확인하지 않는다. 같은 영상이 두 번 보이게 된다.

## 근거 사례

doko PR #562. 영상 줄을 맨 경로로 써서 첫 업로드가 본문 끝에 붙었다. 링크로 고쳐 다시 올린 영상이 검증 항목 아래에 따로 들어가, 같은 영상이 두 번 보였다. 사용자가 발견해 본문 끝 줄을 지웠다.
